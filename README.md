# Stillwell website prototype

A responsive, static landing page prototype for a mental healthcare provider-matching service.

## Run locally

Open `index.html` in a browser, or serve the project directory with any static web server.

## Prototype notes

- The provider profiles are fictional examples and are clearly labeled as such.
- The matching survey runs entirely in the browser. It does not save or transmit answers.
- Survey results are suggestions for exploring the example profiles, not clinical assessments or guaranteed matches.
- Replace the sample profiles and contact flow with verified provider details and an appropriate, privacy-reviewed backend before using this as a live service.
